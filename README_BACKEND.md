# Backend Node.js do Evolua

O backend foi criado em [`backend/`](./backend). Ele expõe uma API REST sobre o Firebase Admin SDK, com autenticação por Firebase ID token e autorização para visitantes, escolas e administradores.

Consulte [`backend/README.md`](./backend/README.md) para configuração, execução e endpoints. O frontend original foi preservado e continua funcional com a integração Firebase existente; a adoção da API REST pode ser feita gradualmente.
